# 🛒 Add To Cart
**Live:** [https://add-to-a-shopping-list.netlify.app/](https://add-to-a-shopping-list.netlify.app/)

**Description:**  
A mobile-friendly shopping list app that allows users to easily add, view, and delete items. Leverages Firebase for real-time data storage and provides a seamless, intuitive user experience.

## 🎮 Features
- **Real-Time Item Management:** Add and delete items instantly
- **Firebase Integration:** Persistent cloud storage of shopping list
- **Mobile-Optimized Design:** Responsive interface for smartphone use
- **Tile-Based Item Display:** Easy-to-read item tiles
- **Simple Delete Functionality:** Remove items with a single click

## 🛠️ Tech Stack
- **Frontend:**
  - HTML5: Semantic markup
  - CSS3: Responsive styling
  - JavaScript: Interactive functionality
- **Backend:**
  - Firebase: Real-time database and cloud storage

## 🛠️ Installation and Running Locally
1. **Clone the Repository:**

   ```bash
   git clone https://github.com/your-username/add-to-cart.git
   cd add-to-cart
   ```
2. **Set Up Firebase:**
   - Create a Firebase project
   - Add your Firebase configuration to the project
3. **Open the Project:**
   Use a local server to run the application
